About this tool

The Field View shows a visual diagram of the throwing circle and distance markers, with an animation of the shot travelling to where it landed. Everything shown in the animation is also given in plain text, so the tool works whether or not you can see or interpret the animation.

The Results view is the quickest way to check exact numbers: athlete name, throw number, distance and personal best, all as text.
